# Atrévete-te-te

Actividad interactiva en HTML para trabajar la canción Atrévete de Calle 13.

## Qué incluye

- Huecos para completar los imperativos.
- Huecos de escucha marcados en color distinto.
- Corrección visual de aciertos, errores y respuestas sin tilde.
- Glosas culturales en inglés y términos de spanglish resaltados.
- Navegación rápida entre estribillo y repeticiones.
- Enlace directo al vídeo de YouTube.

## Uso

1. Abre [index.html](index.html) en un navegador.
2. Completa primero los imperativos.
3. Usa Revisar todo para comprobar respuestas.
4. Completa después los huecos de escucha.
